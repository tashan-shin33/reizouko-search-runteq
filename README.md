## 1. サービス概要

冷蔵庫カタログ内容をデータベース化し、欲しい冷蔵庫を迅速に検索するアプリです。  
家電量販店の店員や個人ユーザーにとって、カタログから欲しい冷蔵庫を探すのは手間がかかります。  
そこで、展示冷蔵庫や業界全体の製品から、ユーザーの条件に合った冷蔵庫を素早く見つけられるサービスを提供します。

---

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情

家電量販店で売り場を担当していた際、カタログ確認に時間がかかり、1日の販売台数に限界を感じていました。

### 2-2. なぜそれが気になったのか

お客様に最適な商品を迅速に案内することが店員の責務であり、それを効率化したいと考えました。

---

## 3. 課題の整理

### 3-1. 表に見えている困りごと

お客様と一緒にカタログを確認するのに時間がかかり、次の接客に移れない。

### 3-2. 本当に解決したい課題

なぜ時間がかかるのか？  
→ カタログの情報量が多く、目的の情報にたどり着きにくい  

なぜそれが問題なのか？  
→ 接客中にお客様を待たせてしまう  

なぜそれが困るのか？  
→ 顧客満足度の低下や販売機会の損失につながる  

**本当に解決したい課題：**  
接客中でも短時間で最適な商品提案ができる状態を作ること

### 環境
- 家電量販店の店頭  
- 店員と対話しながら商品を検討

## 7. 実現すること

### データベース構築

- 初期は手動登録  
- MVPでは対象を限定  
- 将来はCSV・API連携を検討  

外部APIは現時点で未定のため、MVPでは手動対応。  
将来的に効率化を図る。

## 10. 技術スタック

### 使用技術

- フレームワーク：Ruby on Rails  
- DB：PostgreSQL  
- デプロイ：Render  
- ライブラリ：Ransack / Devise  

### 技術選定理由

- Rails：開発効率が高い  
- チャレンジ：検索機能強化  
- 不安：パフォーマンスと設計
